
# نظام الجدارة الزمنية والتعاون الحي (Chronos-Value System)

نظام مالي واقتصادي لامركزي مستقل، يعتمد على "ساعة العطاء البشري" كوحدة تبادل.
لا بنوك مركزية، لا ربا، لا تعدين استهلاكي، ولا احتكار للثروة.

## المبادئ الفلسفية
1. **ساعة الجهد = وحدة القيمة**: كل عمل بشري (خدمة، سلعة، تعليم، رعاية) يُقاس بساعات العطاء.
2. **ديناميكية الرصيد (Demurrage)**: الأرصدة المعطلة تتراجع تدريجياً (0.5% شهرياً) لإجبارها على الدوران.
3. **خلو النظام من الربا**: لا فوائد مركبة، لا رسوم تحويل.
4. **السيادة المحلية**: كل مستخدم يملك محفظته وسجله على جهازه.
5. **التحقق الرياضي**: لا يمكن إنفاق ساعات غير موجودة.
